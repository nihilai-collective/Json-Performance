# Json-Performance: Correctness Validation
Correctness validation of JSON libraries (Compiled and run on Linux 7.0.0-1019-azure using the GCC 16.0.1 compiler).  

Latest Results: (Nov 14, 2026)
#### Using the following commits:
----
| Jsonifier: [d4727ec](https://github.com/nihilai-collective/Jsonifier/commit/d4727ec)  
| simdjson: [449f38e63](https://github.com/simdjson/simdjson/commit/449f38e63)  

#### Active Implementations:
| Library | Active Implementation |
| ------- | --------------------- |
| Jsonifier | `AVX2` |
| simdjson (stage-1) | `haswell` |

>> In these tests, we are comparing the 'json structural tape' generated by each of the libraries during their 'stage-1' parsing. The simdjson tape is read directly from upstream simdjson's internal `dom_parser_implementation` after `stage1()`, with no fork or patch required.
