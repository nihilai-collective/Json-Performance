# Json-Performance
Performance profiling of JSON libraries (Compiled and run on Linux 6.17.0-1022-azure using the GCC 16.0.1 compiler).  

Latest Results: (Sep 03, 2026)
#### Using the following commits:
----
| Jsonifier: [ffd3253](https://github.com/nihilai-collective/Jsonifier/commit/ffd3253)  
| Simdjson (On Demand): [7002cd3](https://github.com/RealTimeChris/simdjson/commit/7002cd3)  

#### Active Implementations:
| Library | Active Implementation |
| ------- | --------------------- |
| Jsonifier | `AVX2` |
| simdjson (ondemand) | `haswell` |

>> In these tests, we are comparing the 'json structural tape' generated by each of the libraries during their 'stage-1' parsing. You can view the branch that was created on the simdjson repo to facilitate this comparison [here](https://github.com/RealTimeChris/simdjson/commit/7002cd32).
