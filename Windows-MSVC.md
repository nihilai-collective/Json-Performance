# Json-Performance: Correctness Validation (AVX512)
Correctness validation of JSON libraries (Compiled and run on Windows 10.0.26100 using the MSVC 19.51.36260.0 compiler).  

Latest Results: (Nov 07, 2026)
#### Using the following commits:
----
| Jsonifier: [3e5ab01](https://github.com/nihilai-collective/Jsonifier/commit/3e5ab01)  
| simdjson: [7002cd3](https://github.com/nihilai-collective/simdjson/commit/7002cd3)  

#### Active Implementations:
| Library | Active Implementation |
| ------- | --------------------- |

| simdjson (ondemand) | `icelake` |
